Quanto custa um site para uma clínica?

Uma página de apresentação custa 490 € (preço fechado, sem IVA). Para uma página por tratamento, blogue ou várias línguas, a Página profissional custa desde 1090 €.

Dá para ligar o site a um sistema de marcações?

Sim. Se já usas um sistema de marcações online, pomos o botão ou a agenda no site. Se não usas, o formulário e o WhatsApp funcionam bem para começar.

Podem escrever os textos dos tratamentos?

Sim. Escrevemos os textos a partir da tua informação e tu revês antes de publicarmos.

O domínio e o site ficam meus?

Sim. O domínio é registado em teu nome e tens acesso a tudo. Se um dia quiseres mudar de empresa, entregamos os ficheiros sem custos.
